NetGuard IDS Platform

NetGuard IDS Platform is a browser-based Intrusion Detection System dashboard for network traffic analysis, live monitoring, anomaly detection, threat detection, SIEM integration, honeypot monitoring, mitigation planning, and cybersecurity case studies.

## Purpose

The purpose of this project is to demonstrate how a modern security monitoring dashboard works. It simulates packet traffic, generates threat alerts, tracks suspicious connections, monitors honeypot activity, displays SIEM forwarding status, and explains incident response workflows.

## Main Features

- Live network traffic dashboard
- Packet capture target management
- Alert generation and filtering
- Suspicious connection monitoring
- Honeypot interaction tracking
- SIEM connector simulation
- Database schema explanation
- Mitigation playbook
- AI-style threat analysis panel
- Case studies for cybersecurity incidents

## How to Run

Open `index.html` directly in a browser, or use VS Code with the Live Server extension.

### VS Code Steps

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server**.
